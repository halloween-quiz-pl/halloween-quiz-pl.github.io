# Halloween Quiz

Quiz for SushiBang Resto.Bar Katowice and Labirynt (Poznań, Wrocław). Answer all 10 questions to get a dessert coupon valid until 30.11.2026.

- `index.html`: the whole site (GitHub Pages)
- `apps-script/Code.gs`: Google Apps Script that checks answers, issues coupon codes and writes every attempt to the Google Sheet
